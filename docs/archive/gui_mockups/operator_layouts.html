Show the screenData: a real PROD run on the Teensy (TEENSY-20071290). Same header in all three; only the main area changes.

A. Step table: one row per test step, one column per channel

Limits are common to all 8 channels, so each step row carries one Low/High and the 8 measurements beside it, each cell green or red with a ✓ or ✗. The live signal is 8 small strips on the left (own y-scale each). Densest: every number on one screen, the usual test-equipment look.

B. Channel rows: one row per channel, its step table beside it

Each channel is one row: live strip, verdict, reason. Click a row (or a failed one is picked first) and the right panel lists that channel's steps with name, Low, High, measured value, result and code. Reads like a checklist per channel; one channel's numbers at a time.

C. Step gauges: each step drawn against its limits

The sequence runs top to bottom. Each step shows its name, limits and result, and a gauge: the green band is Low…High and each channel is a numbered dot, so which channel is out, and by how much, is visible without reading numbers. Values beyond the gauge sit at the edge with their number. Hover a dot for its value.
